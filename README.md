# Centipede Arcade

A classic Centipede-style arcade shooter for Android, built as a single-file Kotlin game on Canvas.

- 28x26 mushroom field, centipede splits when shot, waves speed up and add solo heads
- Spider sweeps the player zone and eats mushrooms; the flea drops mushrooms when the bottom gets sparse
- Drag to move, hold to fire, 3 lives, persistent high score
- No permissions, no network, no dependencies

Sideload the APK from the [releases page](https://github.com/trypod33/centipede/releases).
